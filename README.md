# OrangeHRM Manual Testing Project

## 📌 Project Overview

This project demonstrates a structured manual testing approach for the OrangeHRM web application.

The objective was to verify major user workflows, functional behavior, input validations, access control, and selected boundary and security-oriented scenarios.

## 🧪 Application Under Test

- **Application:** OrangeHRM
- **Testing Type:** Manual Testing
- **Testing Approach:** Functional Testing
- **Browser:** Google Chrome
- **Operating System:** Windows
- **Test Environment:** Public OrangeHRM demo environment

## 🎯 Testing Scope

The following modules and functionalities were covered:

- Login and Logout
- Admin – User Management
- PIM – Employee Management
- Leave Management
  - Apply Leave
  - My Leave
  - Leave List
- Input validation
- Boundary validation
- Role-based access control
- Selected security-oriented scenarios

## 🔍 Testing Activities

The following testing activities were performed:

1. Requirement analysis
2. Test scenario design
3. Test case preparation
4. Positive testing
5. Negative testing
6. Input validation testing
7. Boundary value testing
8. Access control testing
9. Security-oriented testing
10. Test execution
11. Result documentation
12. Test closure

## ⚠️ Testing Limitations

Testing was limited to the defined functional scope, selected modules, available test data, and the public demo environment.

The following were not covered in this testing cycle:

- Performance testing
- Load testing
- Stress testing
- Cross-browser testing
- Full security penetration testing
- API testing
- Mobile application testing

## 🏁 Conclusion

The planned manual testing activities were completed for the defined scope.

All 28 planned test cases were executed successfully, with 28 test cases passed and no confirmed defects identified within the testing scope.

This project demonstrates the complete manual testing workflow from requirement analysis through test execution and test closure.
